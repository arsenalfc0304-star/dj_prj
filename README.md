# Проект dj_prj

## Описание:

Проект oop_prj - это приложение на Python для реализации проекта интернет-магазина.

## Установка:

1. Клонируйте репозиторий:
```
git clone git@github.com:arsenalfc0304-star/dj_prj.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
